Caso de estudio

Alke Wallet: Sistema Integrado de Billetera Virtual en Django con gestión relacional de clientes, cuentas y transacciones SQL.

Descripción de la actividad

Desarrollo de una plataforma web bancaria completa con panel de administración para gestionar registros de clientes, cuentas asociadas, movimientos financieros y reportes SQL personalizados.

Desafío principal

Conectar la lógica backend en Django con consultas SQL relacionales garantizando la integridad de las transacciones y presentar un panel dark-mode responsivo.

Solución propuesta

Implementación del patrón de arquitectura MVC con Django ORM, validación de formularios, estilos personalizados con Bootstrap 5 e integración de botones de acción rápida para edición y reporte.

Herramientas técnicas

Python 3.14, Django Web Framework, SQL (vía SQLTools en VS Code), Bootstrap 5, Git/GitHub y entornos virtuales venv.

Principales aprendizajes

  • Diseño de relaciones y claves foráneas en tablas relacionales.
  • Aislamiento de entornos con venv y control con .gitignore.
  • Creación de interfaces web oscuras limpias con componentes Bootstrap 5.

Habilidades técnicas

Desarrollo backend con Django, consultas SQL, maquetación web responsive, manejo de vistas/plantillas y control de versiones con Git.

Métricas de impacto

Tiempo de resolución

Reducción del 40% en tiempo de maquetación con Bootstrap 5.

Mejoras funcionales

Gestión ágil de clientes con acciones dinámicas de edición.

Eficiencia

100% de aislamiento de paquetes mediante el uso de venv.

Cobertura

Integridad de transacciones asegurada con claves foráneas SQL.

Por qué lo elegí

Elegí Alke Wallet por ser la culminación de mi recorrido técnico, donde logré integrar mis primeros conocimientos de maquetación con una base de datos relacional y un backend en Django robusto.
